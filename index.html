// what it does

Everything you need. Where it should be.

The TUI stores everything in ~/.fungible. No account required.

Bank sync via Plaid

Connect checking, savings, credit, and investment accounts via Plaid. Transactions pull automatically with a 15-minute debounce and a force-sync option.

CSV import

Import statement exports from any bank. Flexible column mapping, duplicate detection against Plaid imports, and soft-delete for cleanup.

Category rules

Substring and regex rules with optional amount filters auto-categorize transactions on sync. Name rules let you rename how payees display.

Spending trends

Bar charts for expenses, income, or any category, aggregated by week, month, quarter, or year. Delta mode shows deviation from your rolling averages.

Net worth tracking

Balance history across all accounts, plus manual assets like a house or car. Scroll by week, month, quarter, or year. View by account or by type.

FIRE & financial health

Cash and liquid runway, FIRE number with progress bar, Coast FIRE, and years to retirement. Adjustable assumptions with live recalculation.

Tags

Label transactions across accounts — trips, projects, events. View income, expenses, and category breakdowns per tag.

Manual assets

Track a house, car, or any other asset by name and value. Shows up in net worth alongside your bank accounts and investments.

Daily backups

Your database is backed up to ~/.fungible/backups/ on startup once per day. Keeps the last 7 by default.

// mcp server

Ask Claude about your finances.

Fungible ships with a built-in MCP server. Point Claude Desktop at it and you can ask natural-language questions about your spending, run summaries, add rules, and more — directly from Claude.

stdio mode always works, even when the TUI is closed.
http mode updates the TUI instantly while it's running.

claude
you     Any Venmo payment over $100 is probably babysitting. Add a rule for that.
claude  Done. Rule added: "Venmo" → Babysitting, min $100.00. Matched 3 existing transactions — all recategorized.
you     How much have I spent on babysitting this year?
claude  $680 across 5 payments — averaging $136 a session.
